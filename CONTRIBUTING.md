# Contributing to EZChart

Спасибо, что хочешь помочь! 🎉

## Как контрибьютить

1. **Fork** репозиторий
2. Создай ветку: `git checkout -b feature/amazing-feature`
3. Коммить в [Conventional Commits](https://www.conventionalcommits.org/) формате:
   - `feat: add paper trading`
   - `fix: handle empty photo`
   - `docs: update deployment guide`
4. Push: `git push origin feature/amazing-feature`
5. Открой **Pull Request**

## Требования к PR

- ✅ Все тесты проходят (`pytest`)
- ✅ Линтер чист (`ruff check src/`)
- ✅ Обновлена документация (если нужно)
- ✅ Описание объясняет **что** и **почему**, а не только **как**

## Code Style

- Python 3.11+
- Line length: 100
- Type hints обязательны для публичных функций
- Docstrings — Google style

## Первые шаги

Посмотри issues с лейблом `good first issue` — они идеальны для старта.

## Вопросы?

Открой Discussion или напиши в Issues.
